# 李一帆 / 设计作品集 2026 · 中文说明

本站由 `Portfolio - Yifan Li.pdf`（15 页，页面尺寸 1920 × 2500 磅）按原稿逐页还原而成。

## 术语对照

| 英文 | 中文 | 说明 |
| --- | --- | --- |
| sheet / page | 页面 | 一个 `.page` 元素对应 PDF 的一张纸 |
| aspect ratio | 宽高比 | 1920 ÷ 2500 = 0.768，竖版 |
| caption | 图注 | 每页右下角那行作品名 |
| divider | 分节页 | 只有居中一个词的空页（Graphic / Software） |
| container query unit (`cqw`) | 容器查询单位 | 1cqw = 该页宽度的 1%，字号随页面缩放 |
| portrait layout | 竖屏布局 | 窄屏下由绝对定位改为单列流式排列 |
| lightbox | 灯箱 | 点图片放大、按 Esc 关闭 |

## 还原方式

- **页面比例**：每个 `.page` 固定 `aspect-ratio: 1920/2500`，与 PDF 纸张一致。
- **坐标**：图片和图注的落点直接取自 PDF 里的实际坐标，换算成页面宽高的百分比，所以位置与原稿对齐，而不是"看着差不多"。
- **字号**：PDF 里的字号（磅）÷ 页宽 1920 × 100 = `cqw`。例如标题 200 磅 → `10.4167cqw`；图注 55 磅 → `2.8646cqw`。页面变宽变窄，字号同比例跟随。
- **配色**：底色 `#ebebeb`，封面与标题墨色 `#454545`，正文与图注纯黑 `#000000`，封面"2026"的蓝 `#2a56a5`。这四个值都是从 PDF 文本颜色和页面像素里取出来的。
- **字体**：封面、分节页、"Bio"等标题用 Courier New（等宽打字机体）；正文与图注用 Calibri。Calibri 只在 Windows 上有，所以从 Google Fonts 引了度量兼容的 Carlito 作为兜底，换行位置不会错位。
- **封面右上角的 "Li"**：不是图片，是 8 行等宽字符（`-`、`|`、`/`、`.`、`------`）在 97.1 磅 Courier Bold、行距 0.653 下排出来的，和 PDF 里的做法相同。

## 图片

18 张图全部按 PDF 内嵌的原始分辨率导出，没有降采样。照片类转 JPEG（质量 90），软件截图保留 PNG（界面边缘和文字更干净）。总计约 4 MB。

## 竖屏（手机）

宽度小于 760 像素时，页面不再按坐标摆放，而是改成单列：图占满宽、图注右对齐跟在下面，字号改用适合手机阅读的档位。配色和字体不变。已在 400 像素宽度实测：无横向溢出。
